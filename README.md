**Vishwa-Vani** is a high-performance, open-source digital sanctuary for exploring the depth of Vedic literature. Built with an unwavering focus on accessibility, modern design (Apple Glassmorphism), and performance, it combines ancient wisdom with Next.js 14, React Server Components, and Edge computing.

---

## ? Core Capabilities

- ?? **Comprehensive Library (100% Gold Books)**: Isha Upanishad, Kena Upanishad, Bhagavad Gita, and Stotras are 100% complete. Mahabharata, Bhagavata Purana, Vishnu Purana, Garuda Purana, Yoga Sutras, and Samskaras are actively progressing through the Gold Pipeline.
- ?? **Autonomous Data Engine**: A highly optimized, local AI-driven pipeline that systematically gathers (Bronze), cleanses (Silver), and translates/expands (Gold NVF 1.3 Schema) ancient literature flawlessly.
- ?? **Vedic Labs & Daily Upliftment**: Interactive experiential modules including Chanting Trainers, Cosmic Timelines, and a localized Daily Upliftment semantic widget designed for immediate, practical human benefit.
- ?? **AI NLP Semantic Search**: Embedded @xenova/transformers dynamically intercepts natural language questions and provides synthesized answers directly alongside scripture citations.
- ?? **Multilingual & Multi-Author**: English, Hindi, and Marathi translations combined with absolute best public domain commentaries (Shankara, Ramanuja, Madhva, Prabhupada, Vivekananda, Dnyaneshwari).
- ?? **High-Performance Architecture**: SSR-first, Edge-optimized routing, Apple Glass UI aesthetics, and an evolving LLM architecture designed for scale.
